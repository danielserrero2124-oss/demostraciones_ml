# Demostraciones — Machine Learning

Jupyter Book con las demostraciones de la tarea de Machine Learning (Universidad del Norte).

**Autor:** Daniel Serrano Romero

El libro se publica automáticamente en GitHub Pages con cada `push` a `main` (ver `.github/workflows/deploy.yml`).

## Construir localmente

```bash
pip install -r requirements.txt
jupyter-book build .
# abrir _build/html/index.html
```
